Экспорт для хостинга

Скачай library.json и загрузи его на GitHub рядом с index.html. Сайт автоматически подтянет книги для всех.

🌐 Инструкция по бесплатному хостингу (GitHub Pages)

  1. Зарегистрируйся на github.com (бесплатно)
  2. Создай новый репозиторий (кнопка "New"), назови например dragonms-wiki, сделай Public
  3. Нажми "uploading an existing file" и загрузи: index.html (это твой dragonmswiki.html, переименуй!), папку img/ и library.json
  4. В репозитории зайди в Settings → Pages, выбери ветку main и папку / (root), нажми Save
  5. Подожди 1-2 минуты. Сверху появится ссылка вида https://твой-ник.github.io/dragonms-wiki/
  6. Скинь ссылку другу — он откроет и будет читать книги!
  7. Когда добавишь новые книги — снова нажми "Скачать library.json" и обнови файл в репозитории
