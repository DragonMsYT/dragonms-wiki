📦 Экспорт для хостинга (чтобы книги были у всех)

Чтобы книги были доступны всем посетителям сайта без бэкапов, загрузи этот JSON файл на хостинг рядом с dragonmswiki.html под именем library.json. Сайт автоматически подтянет книги оттуда.

ℹ️ Инструкция по хостингу

  1. Создай репозиторий на GitHub
  2. Загрузи туда dragonmswiki.html и папку img/
  3. Нажми "Скачать library.json" и загрузи его в корень репозитория
  4. Включи GitHub Pages в настройках репозитория
  5. Готово! Сайт будет доступен всем, книги подтянутся автоматически
