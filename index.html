Скачай library.json и загрузи его на GitHub рядом с index.html.

Инструкция по GitHub Pages

  1. Зарегистрируйся на github.com
  2. Создай репозиторий (например dragonms-wiki), сделай Public
  3. Загрузи: index.html, папку img/, library.json
  4. Settings → Pages → Source: GitHub Actions → Configure (Static HTML) → Commit
  5. Сайт будет по адресу https://твой-ник.github.io/название-репо/

🖼️ Выбрать фон сайта

Выбери обложку произведения в качестве фона. Текст будет читаться на полупрозрачной плашке.
