# Last Way Fandom Wiki

Библиотека и энциклопедия произведений Драгона Мс.

[Открыть сайт](https://dragonmsyt.github.io/dragonms-wiki/)

Обновление от 13 ноября 2026 года: 14 завершённых произведений и 47 статей энциклопедии. Заметки, планы, случайные короткие тексты, незавершённые произведения и дублирующие редакции исключены из публичной библиотеки; исходные файлы сохранены в репозитории.

## Тексты и оформление

- Первая часть «Лапок» представлена завершённым оригиналом 2023 года. Незавершённый ремейк и третья часть не включены в библиотеку.
- «Застрявшие в лесу» сохранены как законченная история, несмотря на планы будущей переработки.
- Для вторых «Лапок» оставлена основная завершённая редакция «Пророчество».
- История о вентиляторе опубликована целиком из авторского PDF. Ранний DOCX доступен среди её дополнительных исходников.
- Обложка истории о вентиляторе показывает только вентилятор. Фон Мицуко заменён новым авторским изображением под сакурой; для нескольких книг использованы предоставленные автором превью.
- Тексты сохранены в авторской редакции. Энциклопедия содержит спойлеры под предупреждениями.

## Содержимое репозитория

- `index.html` — интерфейс, читалка и редактор.
- `library.json` — книги, метаданные и статьи энциклопедии.
- `img/` — обложки, фоны и иллюстрации.
- `sources/` — исходные документы опубликованных книг.
- `publication-inventory.json` — учёт опубликованных исходников.
- `.github/workflows/static.yml` — публикация GitHub Pages при обновлении `main`.

## Локальный просмотр

Запустите статический HTTP-сервер из корня репозитория, например `python -m http.server 8766`, и откройте `http://localhost:8766/`. Библиотека загружается отдельным JSON-файлом.

Прямые ссылки имеют вид `#book=book_…` и `#lore=locations/lore_…`. Позиция чтения и оформление сохраняются в браузере. Серверный `library.json` обновляет библиотеку при открытии страницы.

Редактор Dev сохраняет изменения локально в браузере. Для общей публикации нужно обновить `library.json` в репозитории.
